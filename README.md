# AI Productivity Hub

Build a modern, professional and responsive web application called "AI Career & Workplace Productivity Assistant".

PURPOSE:

Create a single integrated AI productivity platform that helps students, graduates and workplace professionals complete common administrative and professional tasks more efficiently.

The application must demonstrate practical AI implementation, strong prompt engineering, responsible AI usage and a professional modern UI/UX.

CORE AI FEATURES:

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner / Scheduler

AI Workplace Chatbot

APPLICATION LAYOUT:

Create a modern SaaS-style dashboard.

Use:

Left sidebar navigation

Top navigation bar

Responsive main content area

Modern cards

Professional typography

Clear visual hierarchy

Consistent spacing

Responsive desktop and mobile layouts

Loading states

Empty states

Error states

Success feedback

SIDEBAR NAVIGATION:

Dashboard
Email Generator
Meeting Summarizer
Task Planner
AI Assistant
Settings

DASHBOARD:

Create a professional dashboard containing:

Welcome message

Short explanation of the platform

Four feature cards

Quick action buttons

Recent activity

Productivity statistics

EMAIL GENERATOR:

Create a form containing:

Recipient/audience

Purpose of email

Key information

Tone

Tone options:

Formal

Friendly

Persuasive

The AI must generate:

Appropriate subject line

Professional greeting

Clear email body

Professional closing

Include:

Generate Email button

Copy button

Edit button

Regenerate button

Clear button

MEETING NOTES SUMMARIZER:

Create a large text input where users can paste meeting notes.

The AI output must be divided into:

Meeting Summary

Key Discussion Points

Decisions Made

Action Items

Deadlines

Responsible People

Do not invent information that is not contained in the notes.

Include copy, edit, regenerate and clear functionality.

AI TASK PLANNER:

Allow users to enter multiple workplace or study tasks.

Each task should include:

Task name

Description

Priority

Deadline

Estimated duration

The AI should:

Prioritize tasks

Organize them into a daily or weekly schedule

Consider urgency and importance

Consider deadlines

Consider estimated duration

Recommend an efficient order

Explain why tasks were prioritized

AI WORKPLACE CHATBOT:

Create an interactive conversational AI interface.

The assistant should help with:

Workplace productivity

Professional communication

Task planning

Meeting preparation

Organization

General workplace questions

Include:

Chat input

Send button

User messages

AI messages

Loading indicator

Clear conversation button

PROMPT ENGINEERING:

Design the AI features using structured prompts containing:

Role

Task

Context

User input

Constraints

Output format

Accuracy requirements

The AI should not fabricate facts.

When information is missing, clearly state that the information was not provided rather than inventing it.

RESPONSIBLE AI:

Add a visible Responsible AI section.

Display the following message:

"AI-generated content may contain errors or inaccuracies. Always review and verify AI-generated information before using it for important decisions or professional communication. Do not enter passwords, financial information, confidential company information, medical information or other sensitive personal information."

Also include appropriate validation and error handling.

UX REQUIREMENTS:

Make all navigation functional.

Make forms easy to understand.

Use clear labels and helpful placeholder text.

Show loading states while AI responses are being generated.

Show useful error messages if generation fails.

Allow users to edit AI-generated results before using them.

Make the application look like a real professional SaaS product rather than a basic student project.

Do not create multiple separate applications. Everything must be integrated into ONE dashboard.

Use reusable components and maintain a clean project structure.
