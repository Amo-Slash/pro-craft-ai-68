# AI-Productivity-Assistant

## Project Overview
Veridian WorkOS is an AI-powered workplace productivity assistant designed to help professionals automate repetitive workplace tasks. The platform combines multiple AI-powered tools into a single integrated dashboard, enabling users to draft emails, summarize meetings, plan schedules, and access workplace assistance efficiently.

## Features
- **Smart Email Generator** — Generate professional emails with tone variations (formal, friendly, persuasive) adapted to the audience (client, manager, team).
- **Meeting Notes Summarizer** — Convert lengthy meeting notes into concise summaries, extracting key decisions, action items, and deadlines.
- **AI Task Planner / Scheduler** — Generate structured daily or weekly plans, prioritize tasks based on urgency and importance, and suggest time optimization strategies.
- **AI Workplace Assistant** — Interactive chatbot interface that handles user queries and simulates a real workplace assistant experience.

## Tools Used
- **Lovable AI** — For building the modern, responsive web application interface
- **GitHub** — For version control and project hosting
- **Generative AI / Large Language Models** — For generating emails, summaries, task plans, and chat responses
- **HTML, CSS, JavaScript / TypeScript** — Core frontend technologies

## Prompt Engineering
The application uses structured prompts to improve the quality, consistency, and accuracy of AI-generated responses. Each prompt contains:
- **Role** — Defines the AI's persona (e.g., "You are a professional email assistant")
- **Context** — Provides background information about the user and situation
- **Task** — Clearly states what the AI should do
- **Constraints** — Sets boundaries (e.g., word count, tone, format)
- **Output Format** — Specifies how the response should be structured
